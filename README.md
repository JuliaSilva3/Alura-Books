# Alura Books

Este é um projeto de aprendizado desenvolvido durante as aulas da Alura. Trata-se de uma página web responsiva que simula uma loja online de livros, com foco em apresentar lançamentos, mais vendidos e categorias de interesse.

## Tecnologias Utilizadas

* **HTML:** Estrutura da página web.
* **CSS:** Estilização da página, incluindo layouts responsivos.
* **Swiper.js:** Biblioteca JavaScript para criar carrosséis de slides interativos.
* **Boxicons:** Biblioteca de ícones para elementos visuais.

## Funcionalidades

* **Cabeçalho:** Contém logo, título, menu de categorias (desktop e mobile), opções de favoritos e minha estante, além de ícones para carrinho de compras e perfil do usuário.
* **Banner:** Apresenta uma chamada para ação com um campo de pesquisa de livros.
* **Carrossel de Lançamentos:** Exibe os novos lançamentos de livros utilizando a biblioteca Swiper.js para navegação interativa.
* **Card de Destaque:** Apresenta um livro em destaque com descrição e opções de adicionar aos favoritos ou saber mais.
* **Carrossel de Mais Vendidos:** Similar ao carrossel de lançamentos, destaca os livros mais populares.
* **Card de Autora do Mês:** Apresenta a autora em destaque com avaliação, descrição e opções de adicionar aos favoritos ou saber mais.
* **Tópicos Visitados Recentemente:** Lista de links para categorias de livros populares.
* **Seção de Contato:** Convida o usuário a se inscrever para receber novidades por e-mail.
* **Rodapé:** Contém informações sobre o Grupo Alura e seus diversos produtos e comunidades.

## Aprendizados

Este projeto foi desenvolvido com o objetivo de praticar e consolidar os seguintes conceitos aprendidos na Alura:

* Estrutura básica de um documento HTML.
* Utilização de tags semânticas do HTML5.
* Estilização com CSS, incluindo seletores, propriedades e valores.
* Criação de layouts responsivos utilizando Media Queries.
* Integração de bibliotecas JavaScript externas (Swiper.js).
* Utilização de bibliotecas de ícones (Boxicons).
* Organização de arquivos e pastas em um projeto web.

## Status do Projeto

Este projeto foi concluído como parte do aprendizado na Alura e serve como um portfólio das habilidades desenvolvidas.
